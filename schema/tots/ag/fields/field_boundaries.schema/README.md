# field_boundaries

Farmer-readable field boundary workbook.

## Examples

- `example.1.xlsx` shows the simplest useful workbook: one required `fields` sheet, no `fieldid` column, and grower/farm/field names used as identifiers.
- `example.2.xlsx` shows the fully built-out option: `fields`, `growers`, and `farms` sheets with optional `fieldid`, `growerid`, and `farmid` columns.

Use names when that is how the real spreadsheet works. Add ID columns when an application needs stable database identifiers or external-system links.
